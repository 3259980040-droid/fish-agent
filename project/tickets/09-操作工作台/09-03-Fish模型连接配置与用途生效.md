## 完整用户过程

新增或修改连接 → 保存并重读 → 获取模型或填写标识 → 明确测试 → 应用到聊天/视觉或已有检索用途 → 后续请求读取同一配置。

## 本票范围与交接

- 先核现有有效模型读取和凭据保存；把所需单项保存接到运行设置，不复用会同时修改 DSH/QQ/人格的整套初始化向导。
- 连接作为实际配置对象，用途关联该对象；旧有效配置迁入或映射到同一读取，不能保留一套页面连接与一套运行配置互不相认。
- 支持列出、新增、修改、移除连接，编辑地址、模型和凭据；服务不支持模型发现时允许手动填写真实模型标识。
- 配置应用返回保存值、活动用途与生效时点；模型切换按既有预算职责更新真实窗口元数据。语音用途只保留已定接口位置，不交付完整音频链路。

## Acceptance criteria

- [ ] 刷新读回连接和用途；当前实际请求使用的配置与页面一致，不继承 DSH 默认模型或人格。
- [ ] 凭据通过现有保护机制保存；页面只显示是否已设置，不回显密钥或写入交付记录。
- [ ] 保存、测试连接、模型发现及应用分别显示真实结果；不支持列模型时仍能手填模型标识。
- [ ] 移除正在使用的连接时明确替换用途或显示未配置，不静默回退到其他人格或模型。
- [ ] 用途绑定没有生成第二个 Fish、另一份人格或固定 token 上限；未接通语音/检索用途不冒充可用。

## 替换与删除

- 退出新旧入口分别保存模型参数且运行只读其中一份的路径，以及页面临时成功状态。
- 保留必要的真实配置/凭据来源；旧初始化向导中其他独立职责不因本票被误删。
