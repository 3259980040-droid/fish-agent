## 完整用户过程

查找记忆或小结 → 查看来源 → 直接更正条目或发起小结修订 → 合并重复项/删除错误项 → 重新读取和召回 → 看实际结果。

## Acceptance criteria

- [ ] 搜索、创建、更正、删除与合并使用同一记忆源，重开读回结果，错误项退出后续召回。
- [ ] 合并结果保留来源与修订关系，未把模型推测改标为主人确认。
- [ ] 社交信息、语料和各级小结可按对象查看及整理；小结修订显示真实处理中或结果。
- [ ] 词法/语义真实状态与具体失败可查，降级不冒充语义正常；不新增另一套语义存储。
- [ ] 不擅自删除原件、恢复主人已删记录或因记忆操作改变人格与权限。

## 替换与删除

- 替换仅日期时间线的主要只读界面、页面假删除及分散更正入口。
- 退出重复拼来源/重算记忆状态的页面逻辑；现有有效存储、来源链和独立行为继续保留。
