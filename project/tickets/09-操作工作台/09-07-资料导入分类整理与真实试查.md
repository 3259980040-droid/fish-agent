## 完整用户过程

放入资料 → 查看原件/解析/索引进度 → 分类改名或移动 → 打开来源 → 输入问题试查 → 选中命中并查看原件或片段 → 按含义移除。

## 本票范围与交接

- 先接既有原件、附件分块、资料导入/整理/试查与正文抓取路径；不新造网页存储、上传服务器或索引。
- 文本、支持文件和网页使用同一资源关联；不支持解析时仍按既有原件能力保存/打开并说明格式限制。
- 展示原件保存、解析、索引与模型取用的实际范围；分类目录、改名、移动、打开与移除落到真实资料对象。
- 试查调用真实检索引擎并给来源；语义不可用沿现有明确降级。传输上限读取既有配置，1GiB 不写成模型理解承诺。

## Acceptance criteria

- [ ] 导入后原件及资料可重读，已有支持文件/网页入口实际工作，不把文本表单冒充全格式解析。
- [ ] 资料分类、改名、移动、预览、打开和移除反映真实后端状态，原件与索引关联可解析。
- [ ] 长处理有真实进度/结果；未解析或未读部分不被显示为已全部理解。
- [ ] 试查显示真实命中及来源，词法降级/失败如实可见，不虚构引用次数。
- [ ] 复用原大附件链路，不恢复页面硬编码体积限制，不整份大文件塞进普通模型请求。

## 替换与删除

- 退出常驻无结果表单、仅文档列表的主要只读呈现、重复导入与页面独立索引。
- 替换虚构引用次数及临时列表移除；原件物理处置按既有整理规则，不擅自销毁文件。
