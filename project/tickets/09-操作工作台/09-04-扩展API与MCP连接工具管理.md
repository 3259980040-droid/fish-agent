## 完整用户过程

添加已支持类型 → 保存参数 → 连接/发现工具 → 查看名称与说明 → 启用或停用 → 从 Fish 同一目录反映实际能力 → 维护或移除。

## 本票范围与交接

- 先接现有插件登记的保存、发现、启停、移除和目录，不在工作台或页面另存工具名称清单。
- 按实际支持的类型提供表单和必要高级编辑；保存、连接、发现与启用结果分开呈现，失败在对应条目可见。
- 只对已有实现提供安装、更新或重载；缺少实现时显示具体支持情况，不假装兼容任意 AstrBot/MaiBot 插件。
- 本票不依赖模型服务新界面；MCP/插件自身连接参数由工具执行 Module 负责，不在模型配置中再存一份。

## Acceptance criteria

- [ ] 添加/修改/启停/移除操作读写 Fish 实际注册表，刷新后与运行能力目录一致。
- [ ] MCP 可连接/重连、发现工具并查看名称和说明，实际失败能在当前项看到中文原因。
- [ ] 保存参数不会被显示为已经发现工具，发现工具也不会被混成已执行该工具。
- [ ] 仅呈现真实支持的类型和维护动作；没有空按钮、假热重载或默认工具名称筛选限制。
- [ ] 保留 Fish 当前身份与配置，复用宿主表单不把 DSH 注册表或默认提示词引入主聊天。

## 替换与删除

- 对已迁移的管理动作退出对应旧控件；DSH 自己仍使用的插件界面不作为重复实现删除。
