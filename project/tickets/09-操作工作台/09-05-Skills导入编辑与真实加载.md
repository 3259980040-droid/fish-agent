## 完整用户过程

导入技能 → 查看内容 → 编辑保存 → 重新读取 → 启用 → 下一次需要技能的实际处理使用同一内容 → 停用或移除后不再装载。

## 本票范围与交接

- 先核 Fish 实际技能加载来源和宿主编辑能力；确缺加载/管理交接才补到既有工具与运行材料职责，不能把 DSH 有界面包当作接通证据。
- 提供列表、导入、查看/编辑、保存、启停与移除；技能资源按既有 Fish 工作区归属整理，不散落在源码或下载根。
- 装载、修改生效和停用语义有真实结果；复用宿主编辑视图，但人格、模型配置和实际技能来源仍归 Fish。
- 与 MCP 管理是同区不同对象，本票没有功能上必须等待 MCP 完成的前置，不创造技能执行 Agent 或第二套权限。

## Acceptance criteria

- [ ] 导入和编辑内容由真实后端保存，重新打开仍能读取；非支持格式给出具体原因。
- [ ] 启用后实际加载路径能够取得同一份技能；停用/移除会影响真实后续装载，不只是隐藏列表行。
- [ ] 页面说明修改何时生效，加载错误可见，草稿不被后台读取静默覆盖。
- [ ] 技能的导入、启停不替换人格、主人身份或模型用途，不借用 DSH 默认系统提示词。
- [ ] 缺少的最小装载能力实际补齐；未接通项单列，不能用“有 Skills 标签页”判完成。

## 替换与删除

- 退出演示技能列表、仅前端启停及与实际装载脱节的编辑入口。
- 只复用或替换实际需要的能力，不把 DSH 的完整技能/Agent 框架另复制一遍。
