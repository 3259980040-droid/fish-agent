## 完整用户过程

打开任务 → 创建一次/重复计划 → 修改时间与意图 → 暂停/恢复或取消 → 立即运行 → 查同一执行实例及成果/回执。

## 本票范围与交接

- 先集中时间表单转换、计划详情解析、实例/成果关联，再接创建、编辑、启停和运行控件；各页不再猜多套时间字段。
- 直接桥接既有 run_now、计划登记和实例队列；处理现有暂停计划人工实例被 pending/claim 排除的问题。
- 立即运行不改变周期下一次时间；主人明确执行一次时允许暂停计划运行本次，完成后计划仍暂停，不临时恢复再暂停。
- 任务详情包含已有本机/委托任务的实际成果入口；明确委托提醒与自主机会仍按原用途分别履约，不造新的调度器或执行库。

## Acceptance criteria

- [ ] 页面和聊天创建的计划读写同一记录，支持一次/重复时间、时区、内容和目标的创建及修改。
- [ ] 暂停、恢复、取消的实际状态重开可读；立即运行返回同一实例引用，并可继续查看处理结果。
- [ ] 暂停计划手动执行一次后仍暂停，周期计划下一次时间不被手动执行暗改。
- [ ] 执行中、正常不动、履约失败、发送未确认与已确认投递按既有语义显示；提醒不因自主不动而算完成。
- [ ] 成果能打开/取得；取消不冒充已停止底层执行，未确认发送不自动再发。

## 替换与删除

- 替换主要只读的任务呈现、页面散落的时间字段猜测及过时状态映射。
- 复用现有执行路径，退出与新详情重复的旧控件和文案；不新增第二个定时来源。
