## 完整用户过程

读取当前连接与开关 → 修改并保存 → 重连或必要维护 → 重读真实有效状态 → 查看对应故障及恢复详情。

## 本票范围与交接

- 先核设置与通道的既有读写归属，普通设置、连接管理和维护分区；不增加第二个同义开关。
- QQ 连接状态与具体错误来自当前连接；保存、重连和真实在线分别表达，不用自动群发测试证明在线。
- 故障详情、恢复记录、用量/五时间点/索引明细按需展开；对象当页仍显示实际失败原因，不能只留一句“去设置看”。
- 调用已有后台重载/维护能力，必要自动操作沿主人既有授权执行，不要求主人操作电脑；不把所有保存都改成必须重启。

## Acceptance criteria

- [ ] 保存后重读真实连接和开关值，页面与实际服务来源一致，失败保留编辑内容。
- [ ] 连接未配、认证/网络错误、工具失败与发送未确认能看到具体中文原因，正常沉默不算失败。
- [ ] 已有故障聚合/恢复记录、原有诊断数据仍可查看，不新增第二套故障状态机。
- [ ] 维护动作返回真实结果，服务启动中/不可达不被显示成空白或在线；无需主人手动操作电脑。
- [ ] 没有新增群写验收、默认消息重发或因页面配置而扩大/收紧工具限制。

## 替换与删除

- 退出把所有业务表单埋在设置页的旧入口，业务页面迁移后只保留各自唯一写入口。
- 替换显示假在线、错误只在远处出现及重复开关的呈现；既有故障数据与运行记录保留。
