## What to build

主人在所属窗口配置和启停工具，保存值真正控制模型目录及实际执行；已发现工具能调用，失败或拒绝原因返回发起模型，而其他窗口能力不受影响。

## 承接来源与Interface

保留B1/B2；合入各窗口独立工具开关、开启恢复和模型真实工具反馈。

原Settings有效能力查询、catalog/execute、扩展配置与发现、原tool结果协议和所有实际出站调用者；共用注册/连接，启停值归实例。

## Acceptance criteria

- [ ] 已支持CLI/HTTP等扩展的工具名、参数定义及运行配置可编辑/保存，保存、测试/发现、启用分别回读真实结果，不只补表单。
- [ ] 有效按需发现定义进入本轮可调用来源，实际执行不再被初始offered清单误拒；后续请求和目录读取使用本实例当前设置，重新开启能恢复能力。
- [ ] 前端修改→保存→后台生效→结果回原模型→页面回读使用同一实例值，切窗/刷新/重新打开后保留；保存失败不画成已生效。
- [ ] 同一发送能力的两边开启、开/关、关/开、两边关闭四种实际结果成立；后台窗口开启仍能用，另一窗口关闭不能隐藏全局工具或断开共用QQ连接。
- [ ] 目录与执行及最终可控出站消费同一能力判定；关私聊/某群发送仅拒相应能力，不暗中关接收/思考，不另存第二份锁状态或增加审批。
- [ ] 同一次调用的成功、参数错误、被关闭拒绝、工具失败、发送未确认沿原tool_call_id返回所属模型；不只写日志/前端错误，不改用另一窗口权限，不自动重发。
- [ ] 受理与最终异步结果分开，任务、文件/进程输出和结果保持发起实例及默认工作区归属；当前可续接则读真实结果，已结束留到下次材料，不强制新增说明回合。
- [ ] 关闭只影响未交给外部服务的调用/本地待发内容，既有在途结果按真实回执保留；共用安装/连接可保留，原B3研究用途及凭据处置不迁移。
