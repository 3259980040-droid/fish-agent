## 完成后的用户过程

主人交办具体事务 → Fish 从统一目录发现工具 → 在自己的执行循环中调用 → 真实结果／文件关联回主线 → 客户端能打开或取得成果，QQ 私聊交付保留实际结果。完整 QQ MCP 能力保持可发现，群写操作不在本次现场实发。

## 本票范围与交接

- **先行收拢：** 先复用现有工具登记与执行接缝，退出主聊天另抄工具名的筛选表；缺少的工具实现再从 DSH 迁入并接 Fish 自身配置。
- **对应界面：** 本票接通现有聊天、任务／成果入口的实际工具结果与文件打开／下载；07 只汇总真实过程，不替本票补文件执行或成果交付。
- **交接约定：** 给 06 提供计划工具接入及真实执行／投递结果，给 08 提供原件按需取用工具。02 中的“任务”是现有执行任务与成果能力；定时计划的登记／到期逻辑归 06，避免互等。
