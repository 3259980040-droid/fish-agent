## 完成后的用户过程

主人在私聊或任务页建立计划 → 同一记录可查看／修改／取消 → Fish 自身调度到期 → 同一主执行按委托或自主意图处理 → 实际工具／投递结果更新任务页；已接受提醒失败单列，自主不动保留其原意。

## 完成标准（Acceptance criteria）

- [ ] 自建计划可查询/修改/取消，页面显示同一记录，正式重载后计划可读取。
- [ ] 短等待提醒到期有内容和真实回执；无发送内容或失败不算自主沉默完成，未确认不自动补发。
- [ ] 自主意图与消息共用已考虑进度，允许不动，群场景只读/临时根模拟，两小时无人不打扰。
- [ ] 旧群/私聊主动与提醒入口的去向列清，提醒不能被统一回合吞掉。

## 替换与删除

### 2026-10-25 已确定目标：立即、默认与特殊触发

按权威规格4.6、4.10.1、7.6实施；定时单位主人已确认仍是**45分钟**。

- [ ] 立即触发：被@、QQ私聊消息、客户端消息；空闲时第一时间进入处理，忙碌时继续接收合并，按到达顺序接续，不并发主思考，也不因主人身份插队。
- [ ] 默认触发：45分钟定时或累计8条群消息；普通群消息不逐条立即启动思考，不增加等群安静的条件。
- [ ] 两个动作分别执行：思考开始时清零群消息计数，期间继续累计新消息；思考完成后重启45分钟计时。不能合成完成时同时清零，也不依赖发送成功。
- [ ] 特殊触发：Fish调用内置3秒自唤醒工具，填写interest≥0.7满足启动条件；0.7保留为程序固定判断，不改成可选记录或额外兴趣校准。不新增整轮生成耗时超过3秒就失效的资格判断。
- [ ] 连续自唤醒最多3次，既定@/8条/45分钟触发解除连续上限；任务被取走不丢失连续次数，不把三次沉默当成三次调用。具体任务时点/交接在后续Interface设计明确，工具3秒与08文件3秒分批分开实现。
- [ ] 触发只给思考机会，是否行动和投递目标由Fish选择；到期明确提醒仍按本票独立履约。旧巡群辅助职责按目标迁入，不保留另一条独立主思考、生成和发送链。
- [ ] 默认北京时间（中国标准时间、UTC+8）；原有每日记忆整理任务调用04的同一整理程序，不再单独实现内容归纳/索引更新。

结构改造时处理旧调用者和状态的迁移/退役，避免重复计时、消费或投递；本次不将无关故障扩展成新范围，不逐条重复付费实验。

退出重复主动tick、分散生成发送、旧私聊主动与重复冷却；迁仍被使用的辅助职责，保留提醒可靠执行路径。
