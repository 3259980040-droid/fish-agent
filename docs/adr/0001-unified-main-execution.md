# ADR 0001：一个 Fish，一套主执行

- 状态：历史决定保留；实例归属、输入认领与当前九票边界由ADR 0002补充（2026-10-26）
- 背景：客户端、QQ 私聊、群、计划和时钟原先各有生成/发送路径，文件与记忆也按场所分开判断，导致同一句话在不同入口有不同结果，旧的队列与线程池互相竞争。
- 决定：新增 `harness/fish_agent/` 作为唯一装配；所有入口只登记输入（`agent_inputs`）并提交一个回合（`agent_runs`），唯一消费者按来源+会话认领，合并先后到达的输入后跑同一条模型/工具循环；投递按来源分流但回执与五时间点共用一套记录。文件按固定 3 秒窗口归批，批次只提供材料。压缩按原库/会话各自推进检查点。记忆读同一份、按来源标注；整理只有一个可重复程序，由每日、工具和客户端共用。
- 影响：退出了旧的群 pump、私聊直接生成、计划线程池、`context_compaction.auto_enqueue`、按场所隔离的记忆查询和 `models.json` 注册表；设置、人格、计划、插件与技能仍由各自唯一来源持有。
- 例外：`fish_emoji_search` / `fish_emoji_read` 的预览图仍在主执行循环内附加（见 `docs/agents/tools.md`），清理方向是把预览作为受控图像附件走同一执行入口。
