# Fish 使用说明书

适用版本：本机 0.4.6 基础上的源码迭代版。功能核对日期：2026-10-20。本文按当前界面、代码及本机验收记录编写；“当前状态”是核对当日的配置，之后以客户端设置为准。

## 先了解 Fish 的组成

Fish 是这套 DeepSeek 助手的客户端和管理入口。DSH 负责模型会话、文件和终端工具、上下文管理及原生定时执行；QQ 连接把真实消息送进来、把结果发出去。当前主人私聊还接入原版 Tulpa MCP，处理聊天批次、回复计划、收藏表情和发送回执。

界面里的“大肥鱼 · QQ 角色”和“研究员 · 研究角色”分别配置模型连接，分别保存主要对话和记忆。角色影响会话环境；工作权限由程序授权。

## 1. 工作台

**用途：查看整体状态，控制角色服务。**

| 区域 | 作用 |
| --- | --- |
| 大肥鱼卡片 | 查看 QQ 角色状态，启动、停止角色，进入 QQ 消息页 |
| 研究员卡片 | 查看研究运行环境，启动、停止研究角色，进入视频研究页 |
| 消息与视频统计 | 查看 Fish 已收录的收到消息、发出回复、已读视频和问题数量 |
| 最近对话 | 快速查看最近收录的交流内容 |
| 开始对话 | 进入本地对话页 |
| 查看运行记录 | 进入运行事件页 |
| 底部连接状态 | 分别显示 QQ 连接、消息通道、角色服务是否就绪 |

**操作：**打开 Fish 后先看大肥鱼卡片及底部连接状态。需要手机交办任务时，启动 QQ 角色并确认通路就绪；研究视频则启动研究角色，再到视频研究加入任务。停止角色会影响依赖它的工作，先确认没有需要继续执行的任务。

“研究环境已启动”和“自动按兴趣逛 B 站已开启”是两个设置：前者表示环境可用，后者在“视频研究 → 兴趣与计划”开启。

**实际应用：**出门前确认 QQ 工作通路在线；回来后先看哪些任务完成、哪些存在问题，再进入相应详情。

## 2. 对话

**用途：在电脑上处理本地任务，或单独试聊人格。**右上角选择角色和人格，左侧切换历史，中间发送消息。

### 2.1 本地工作：文件与终端

本地工作使用 DSH 原生工具，能读取文本和代码、创建文章、编辑文件、执行脚本或命令，再按实际结果继续处理。

**操作步骤：**

1. 选择“大肥鱼”或“研究员”。
2. 选择“本地工作 · 文件与终端”。
3. 填写或选择“新对话目录”。
4. 选择工具权限，点击“新建对话”。
5. 查看聊天上方的实际目录与权限，再发送任务。

目录输入框用于下一段新工作会话。只改输入框，不会迁移已打开会话；当前会话以聊天上方的实际目录为准。

| 权限或按钮 | 含义 |
| --- | --- |
| 完整本机权限 · 文件与命令 | 使用当前 Windows 账号可用的本机文件和命令权限 |
| 只写工作目录 · 扩展操作需授权 | 使用 DSH 工作目录权限模式，扩展操作按原生授权处理 |
| 应用到当前工作对话 | 为当前工作会话保存选择的权限，在下次发送时应用 |
| 工具与授权面板 | 打开同一 DSH 环境，查看工具或等待授权的状态 |

完整本机权限仍取决于当前 Windows 账号及已安装的软件，不等于所有桌面软件自动拥有可操作接口。

**任务示例：**

> 读取当前目录的 README，说明项目如何启动，再实际执行启动前的环境检查，按结果说明缺什么。

> 在当前工作目录写一篇介绍 QQ 远程助手用途的文章，保存为 Markdown，再读回核对标题和正文。

> 找到项目保存配置的代码，修复我描述的问题，并运行与本次修改直接相关的检查。

文件是否保存、命令是否成功，看真实工具结果。在聊天里生成文章正文，不等于已经保存成文件。

### 2.2 人格聊天：独立窗口

用于比较角色表达、连续对话和临时扮演。本地消息不会自动转发到 QQ。

选择“人格聊天 · 独立窗口”及人格版本，点击“新建对话”后连续聊天。已有窗口换风格时，选择版本并点击“重载当前人格”，保留现有历史；要比较从空白开始的效果，应新建窗口。

人格决定背景、表达和聊天习惯。导入另一项目的人格正文，不会同时安装那个项目的全部工具；文件和终端权限由工作模式及程序授权决定。

### 2.3 消息与附件

- 点击“发送”或按 `Ctrl+Enter` 发送，普通回车换行。
- 可以粘贴图片、拖入媒体，或点击“添加照片 / 文件”。
- 当前附件入口接收图片、视频、语音：每条最多 **3 个附件**，每个不超过 **20MB**。
- 这不是通用 Word、PDF 或项目压缩包上传入口。处理本机文本和源码，可在工作模式给出真实文件路径。
- 图片随本轮消息交给角色模型；视频先提取关键帧与字幕，语音需要已配置的转写工具。
- “停止回复”取消当前生成或等待，不会自动撤销已经完成的文件编辑或外部发送。

### 2.4 历史和本轮输入检查

左侧支持搜索对话、按全部时间、最近 7 天、最近 30 天或指定日期筛选，也能加载更早消息。

“本轮输入检查”展示实际提交给模型的脱敏快照，包括近期消息、人格背景和工具清单。适合检查旧人格是否还在、有没有文件工具、联网工具是否进入本轮请求。

快照省略密钥、媒体原始数据和内部思考，并有长度上限；它反映程序调用模型的边界，不能显示服务商内部处理。

## 3. 视频研究

**用途：发现视频、排队研究、保留资料和看法，再继续提问。**研究资料保存在研究侧。

### 3.1 任务与研究

| 操作 | 用途 |
| --- | --- |
| 现在逛一轮 | 按已保存的兴趣和来源发现内容 |
| 输入 BV 号或视频链接，加入任务 | 直接指定想研究的视频 |
| 暂停 / 继续 | 控制研究队列 |
| 停止所选任务 | 停止选中的任务 |
| 重试所选任务 | 将失败、停止等任务重新排队 |
| 更想看这类 / 少看这类 | 在你设定的方向内调整排序 |
| 在聊天中继续问 | 将主题带到研究员本地对话，准备继续提问 |

选中任务可查看当前步骤、发现理由、错误或研究详情。完成的详情包括摘要、看法、兴趣关联和证据；可观察范围取决于实际取得的字幕及画面。

“在聊天中继续问”只准备本地提问，仍需到对话页发送，不等于已经自动问完或发到 QQ。

### 3.2 兴趣与计划

可设置兴趣方向、关键词、排除词、指定 UP 主；来源包括关键词搜索、指定 UP、选定收藏夹和首页推荐。还可设发现间隔、每天处理量、每轮新增量、视频时长及单任务运行上限。

勾选“自动按计划发现并研究新内容”并保存后，后台才会按计划发现内容。当前本机自动研究关闭，间隔设置为 180 分钟，每天最多 8 条；研究侧额度独立于 QQ 无上限设置。

**实际应用：**方向填“AI 编程工具的实际应用”，关键词填“本地 Agent”“代码助手”，排除不想看的营销内容。先手动逛一轮检查相关性，再决定是否自动研究。

### 3.3 账号与收藏夹

可扫码登录、检查登录状态、读取收藏夹并选择“使用此收藏夹”。扫码后需要手机确认。个人收藏与推荐读取依赖对应登录状态，公开内容搜索的条件不同。

本板块当前负责发现、读取和研究，B 站自动评论、私信及经营动态不属于已启用工作流。

## 4. QQ 消息与主人私聊

**用途：QQ 消息页监看和排查；手机主人私聊直接交办任务。**

### 4.1 QQ 消息页

可以选择 Fish 已收录的会话、搜索消息、按日期筛选，查看连接状态与收到、发出、失败、取消统计；“取消 QQ 在途任务”停止当前处理，“带到本地对话”准备电脑上的草稿。

“带到本地对话”不会把原消息重新发给 QQ 联系人。

原版 Tulpa MCP 有自己的发送和回执记录，部分外发结果尚未完整统一回填本页。因此，这里的条数不能作为所有外发工具的完整总账，核对送达还要看实际 QQ 消息和相应发送工具回执。

### 4.2 主人 QQ 远程工作

当前已开启本机工具权限。真实主人账号发来任务后，Fish 核验身份，找到当前主人会话，由同一 DSH 会话沿用历史，调用文件、编辑、终端或联网工具，再根据实际结果回复 QQ。

未指定位置时，默认产出目录是：

`F:\Downloads\dsh-personal\qq-work\owner-files`

任务中可以指定其他绝对路径。执行使用 Fish 配置的 DeepSeek API，不使用 Codex 对话额度。

**可以直接试的任务：**

> 在默认工作目录写一篇 800 字左右的文章，主题是手机交办电脑任务，保存为“远程办公.md”，读回确认后告诉我路径。

> 读取 F:\Downloads\dsh-personal 的说明，检查启动入口实际指向哪里，把找到的结果告诉我。

> 20 分钟后，在默认工作目录写一份今天的任务小结，保存成文件，再私信告诉我路径。

> 给已配置的白名单群发送一句“今晚九点讨论项目”，成功后告诉我结果。

最后一种属于明确交办的一次发送，走实际发送适配器和白名单目标，不要求恢复该群的自动旁听、回复。本轮工程验收只实际发送主人私聊，没有向群发送测试消息。

### 4.3 主人权限

权限由真实 QQ 号和客户端勾选决定。昵称、“我是主人”的文字、图片或角色设定不能授予身份。

已启用权限包括查看状态、暂停恢复、取消任务、管理人格及群设置、保存删除记忆、安排定时、管理表情和本机工作。普通群友不会因聊天获得编程工具。

权限开关在“系统设置 → 主人与用量”。人格可保留风趣和临时扮演，但不能用角色里的懒或拒绝工作代替实际执行。

### 4.5 实际验收范围

真实 DeepSeek 已完成文章创建、编辑标题、终端执行、读回，以及延后唤醒后生成文件并实际发回主人 QQ；消息已通过真实接口回读。

工程任务从既有主人会话的模型输入入口提交，没有伪造手机 QQ 入站事件。手机连续交办的自然语言理解和对话体验，可以继续用上面例子检验。

## 5. 资源管理

下设插件、长期记忆、表情库三个页签。

### 5.1 插件：接入真实工具

支持 MCP 本地程序、MCP HTTP、MCP SSE、CLI JSON 输入输出、HTTP JSON 接口和 DSH 原生插件。

**接入流程：**新增插件 → 填程序及参数或服务地址 → 单独保存凭证 → 选择角色与范围 → 保存配置 → 测试并发现工具 → 勾选允许调用的工具 → 启用保存。

DSH 原生插件选择含 `package.json` 的本地目录，安装更新时会重启相关角色。停用会停止调用，移除配置不等于删除原项目文件。

工具注册、模型本轮拿到工具、实际执行成功是不同状态：插件页看测试与调用记录，“本轮输入检查”看工具是否进入请求，工具结果看是否真正执行。

新接入插件不一定自动用于每个独立窗口；窗口范围、角色、主人身份和已有适配都会影响可用性，外发工具还需要实际发送通路。

### 5.2 人格、插件和完整项目的区别

| 操作 | 实际带来什么 |
| --- | --- |
| 导入人格 | 背景、表达、行为提示，不自动带来工具 |
| 配置插件 | 可调用工具，仍需要依赖、权限和正确入口 |
| 适配完整工作流 | 收消息、计划、执行、发送、记账等具体流程，需要逐项验证 |

当前已导入 AstrBot、MaiBot、QQ Agent 的部分人格预设及来源，不代表三套机器人整体运行。原版 Tulpa MCP 主人私聊则已接入实际聊天批次、计划发送、收藏表情工具和回执协议。

### 5.3 长期记忆

管理跨轮保留的偏好、事实、关系、共同事件、约定、梗与出处等。QQ 和研究角色分别选择和管理。

| 功能 | 作用 |
| --- | --- |
| 搜索 | 按内容、分类、来源查找 |
| 新增 / 保存 | 人工记录或纠正稳定资料 |
| 来源与原文 | 核查记忆出处 |
| 主体、别称、类型 | 将资料关联到具体账号或虚构人物 |
| 过期时间 | 设置有效期，0 表示不自动过期 |
| 自动学习开关 | 控制符合条件的新聊天提取 |
| 待确认候选、确认候选 | 审阅允许确认的学习结果 |
| 重试失败记录 | 重新处理失败学习任务 |
| 删除并禁止重新学习 | 删除并记录原内容或来源的禁学信息 |

自动学习不是将所有原文永久写入。独立测试窗口有隔离规则，不会自动继承日常主人库；日常记忆、群资料和原版 MCP 学习库也不是一张无区别的表。

主人管理工具可显式操作主人记忆。保存重要资料后，应在记忆页检查条目、来源和可见范围。模型说“记住了”，不能证明已经持久保存，也不能证明所有窗口都能检索到。

**实际应用：**记录“文章默认保存成 Markdown”、某成员稳定别称或已确认的相处偏好。错误资料人工纠正，原自动来源不能覆盖人工修正。

### 5.4 表情库

可导入图片、编辑描述标签、按语境搜索、设置容量与同一聊天发送间隔，删除时可阻止再次收藏。

Fish 本地表情与 QQ 客户端收藏是不同来源。原版 Tulpa 私聊另有 QQ 收藏读取工具，本机已验证收藏列表及原图读取；自然挑选发送仍看本轮实际工具和回执。

**实际应用：**描述写“被发现后装傻”“无语但不生气”“认错”，比只保留文件名更有利于按语境选择。

## 6. 运行记录

**用途：定位实际错误与卡点。**按时间查看事件，可筛选全部、Runtime、QQ、Research、错误，展开摘要和详情。

| 现象 | 建议检查顺序 |
| --- | --- |
| QQ 不回应 | 工作台连接、暂停开关、当前窗口、运行错误 |
| 说没有文件或终端工具 | 本地工作模式、主人本机权限、本轮工具清单 |
| 一直等待 | 工具与授权面板、当前工具、运行记录，必要时取消 |
| 说不能联网 | 请求里有没有 `web_search` / `web_fetch`，调用是否报错 |
| 定时到了没收到 | 最近唤醒、工作结果、发送回执、QQ 实际消息 |
| 改了人格仍像旧版 | 是否只保存未应用、是否在旧窗口、实际版本和本轮输入 |
| 视频研究失败 | 当前步骤、登录、提取工具、网络、研究额度 |

模型普通文本里说“没工具”或“发好了”不能代替程序状态。工具清单、执行结果和发送回执更适合排查。

## 7. 系统设置

### 7.1 主人与用量

保存真实主人 QQ、权限勾选、本机工作权限、暂停状态与用量模式。

| 设置 | 含义 |
| --- | --- |
| 主人权限勾选 | 决定真实账号的管理和工作范围 |
| 主人私聊本机工具 | 私聊及其私聊定时任务可使用原生文件、编辑、终端 |
| 暂停所有 QQ 回复与任务 | 暂停 QQ 角色相关处理 |
| 无上限，继续统计 | 不按每日轮数、消息数、请求数和已报告 token 阈值暂停 QQ |
| 自定义每日上限 | 使用填写的每日预算 |
| 普通聊天每轮工具上限 | 普通聊天工具次数限制；主人本机工作和本地工作不套用 |

QQ 无上限不取消服务商余额或接口限制，研究侧额度独立。token 统计取决于服务商回传，不是精确人民币账单。

当前主人工作消息控制器最多等待 30 分钟，普通聊天更短；它与每日无上限是不同维度。长任务仍应观察运行状态。

### 7.2 模型与 API

为大肥鱼和研究员分别设置名称、模型、API 地址和密钥；密钥留空保留已有值。保存后按页面提示生效，运行中的角色必要时在工作台重启。

人格正文统一到“人格与群聊”编辑，不在此设置。

### 7.3 连接设置

配置 NapCat 地址与密钥、Fish 通道密钥、DSH 启动器和 Node 路径。网络可选系统环境代理、直连、指定 HTTP 代理。

保存网络后需重启运行中的角色，独立插件进程也要按其方式重新加载，本机服务间连接保持直连。连接测试不会自动发送 QQ 测试消息。

### 7.4 媒体与工具

控制图片输入、可选语音转写、QQ 附件自动理解、研究侧多模态补充、视频工具及抽样帧数。

- 图片随本轮进入模型，需要接口实际接受图片输入。
- 语音需要配置好的转写服务，开关不代替安装服务。
- 视频先取关键帧、字幕再理解；抽样不能代表逐帧看完整段。

此页保存配置，日常发图提问在“对话”。

### 7.5 数据与升级

| 操作 | 用途 |
| --- | --- |
| 创建备份 | 备份 Fish 范围内的对话、数据库、记忆、表情、研究和主要配置 |
| 包含可迁移凭证 | 用至少 10 字符密码加密可迁移密钥，便于跨 Windows 账号恢复 |
| 选择备份并恢复 | 校验、确认后退出维护，先保留当前备份，再恢复重开 |
| 选择 Fish 升级包 | 安装已有本地升级包；当前源码日常迭代不要求使用 |
| 重新运行配置向导 | 重新配置角色 API、QQ 和运行环境 |
| 导出脱敏诊断 | 生成用于排查的诊断资料 |
| 选择新目录并迁移 | 选空目录，退出后复制校验、重开，保留原目录 |

外部项目、插件依赖、另选工作目录的文件，不等于都包含在备份中。当前新增 `harness/owner-computer.json` 的自定义默认目录配置尚未列入备份白名单，迁移前需另存；默认产出文件在 `qq-work` 备份范围。

普通 Windows 加密凭证依赖原用户，跨账号应使用可迁移凭证备份，或在新环境重新填写。

### 7.6 回复规则

统一编辑阻断词、正则、分类规则和补充词表。可在草稿中测试，通过后再保存。

“测试全部草稿 · 不发送”检查当前所有草稿，不调用模型、不向 QQ 发消息，也不自动保存。保存后才影响实际检查。

本页调整 Fish 自身规则，不会改变服务商模型的能力与行为边界。角色口气、粗口、篇幅等还受所用模型及当前人格影响。

## 8. 人格与群聊

共有六个页签，集中处理人格、群参与、成员与定时任务。

### 8.1 人格版本

支持导入 Markdown、TXT、AstrBot JSON、MaiBot TOML及社区预设；可查看正文、来源、共同规则快照、工作区规则快照。

**修改应用：**选版本或导入 → 编辑 → 另存为新版本 → 选择主人私聊或白名单群 → 应用并重载。

| 选择 | 对历史的影响 |
| --- | --- |
| 默认不勾新窗口 | 在已有目标窗口重载人格，保留历史 |
| 勾选新窗口 | 新建独立上下文，适合从空白比较 |
| 新建本地测试窗口 | 本地试聊，不向 QQ 发送本地文本 |

保存只产生版本，不直接覆盖已绑定窗口。“对比原版本”看正文变化，“查看主人测试输入”核对实际输入，“主人 QQ 测试指令”查看 QQ 操作方法。

测试输出可选正式回复，或 API 实际返回的最多 160 字思考片段加正式回复；只有接口返回相应内容才有片段，不要求模型编造思考。正式部署与测试输出有各自范围。

**实际应用：**分别保存“自然短接话”“详细解释”“角色扮演较明显”版本，在独立窗口用相同问题比较，再应用到主人私聊。动作、口癖和篇幅是人格偏好，工具权限仍由程序设置。

### 8.2 群聊参与

按白名单群设置旁听、学习、参与方式、消息合并等待、主动冷却、次数限制和主动静默时段。

| 设置 | 用途 |
| --- | --- |
| 允许旁听 | 接收背景消息，保存有界短期上下文 |
| 学习 | 从符合条件的新旁听文字提取候选资料 |
| 只回应提及和回复 | 重点处理 @ 或明确回复机器人 |
| 熟悉群友：合适时接话 | 按当前策略判断主动参与 |
| 消息合并等待 | 给同一人的连续补充留出合并时间 |
| 次数限制 | 控制分钟、小时和无人接续时的次数 |
| 主动冷却、静默 | 控制主动参与间隔与时段 |
| 清理此群旁听记录 | 清理本群短期背景，不删除全部历史及长期记忆 |

明确提问按队列处理、引用对应消息，同一人的连续补充可合并；多人共享群背景，但各条提问保持对应对象。

“保存旁听与频率”不自动打开群回复；“停止此群回复”与旁听开关分别控制。应用人格也不会自动恢复已经停止的群。

“将当前已认可版本发布到此群并开启发言”包含开启群发言动作。当前群按主人要求停止，说明书整理没有改变任何群设置。

关闭群次数限制后，主动冷却、静默仍分别生效；系统设置的 QQ 每日上限是另一层设置。

### 8.3 成员管理

选择白名单群、设为管理群后，可同步基础资料，按昵称、群名片或 QQ 搜索，管理别称、好感度、锁定和相处偏好。

同步只读基础资料。自动关系更新还需要当前管理群开启旁听及学习，锁定成员不自动增减。页面可查看变更，撤销选中数值变化。

评分和详细记录是本地管理资料；普通群回复使用相应行为参数。可记录“喜欢短接话，不喜欢追问”这类明确偏好，或给常改昵称的人保存别称。

### 8.4 日常人格

编辑大肥鱼或研究员的日常人格原文，保存后由日常会话在角色下次启动时加载。

固定版本的测试窗口、已应用版本和群发布不随原文自动改变。当前若在主人固定测试窗口，想立即换风格，应到“人格版本”保存并应用重载。

### 8.5 共享规则原文

编辑两个角色的共享规则来源。已有测试及发布版本使用自己的快照，不随原文自动更新。

共享原文是后续配置来源；版本快照是某一版本实际绑定内容。它们不是自动互相同步的两个编辑器。

### 8.6 定时任务

到期唤醒模型，执行任务正文，再按绑定目标实际发结果。支持主人私聊与白名单群。

| 执行方式 | 场景 |
| --- | --- |
| 延后一次 | 20 分钟后提醒，或稍后生成文件 |
| 指定日期一次 | 某天某时执行 |
| 每隔一段时间 | 周期执行，界面周期最短 60 秒 |
| 每天固定时间 | 每日提醒、资料整理 |
| 每周固定时间 | 按星期执行，1 为周一，7 为周日 |
| Cron | 按明确时间表达式执行 |

**新建：**点击“新建”清空编辑器 → 填名称、目标、时间、时区 → 写明要做什么、文件位置及最后发什么 → 保存任务 → 在列表检查实际时间和状态。

只点“新建”尚未创建任务，必须保存。默认时区 `Asia/Shanghai`。已有任务可修改标题、正文和时间；界面不直接更换已建任务目标，换目标需新建。

**正文示例：**

> 到点后，在默认工作目录写今天的项目小结，保存成 Markdown，读回确认，再把路径发给主人私聊。只执行一次，不创建后续任务。

主人私聊定时会话已接通本机编程工具；群目标定时会话仍使用自己的消息工具范围，不自动获得主人私聊的完整编程权限。

主人 QQ 也能用自然语言安排任务。普通聊天直接创建的原生任务，在列表里可能以原生会话尾号显示目标。

**验收分三步：**最近唤醒表示任务交给模型了；文件或命令结果表示工作完成到哪步；发送回执表示是否送到 QQ。三者分别看。

绑定 Fish 发送器的回执在本页展示；原版 MCP 自身发送还需看其工具回执及 QQ 实际消息，不能只凭本页“暂无回执”判定一定没发。

任务持久保存，但执行需要电脑、Fish 后台和 QQ 连接在线，当前不能在关机期间执行。

## 9. 数据、历史与记忆

### 9.1 四种资料

| 类型 | 保存什么 | 用途 |
| --- | --- | --- |
| 聊天历史 | 原消息、回复和相关会话记录 | 回看、继续同一窗口 |
| 模型当前上下文 | 本轮历史、摘要、人格及工具结果 | 理解当前任务 |
| 长期记忆 | 已保存或学习的结构化资料 | 按可见范围检索稳定信息 |
| 执行回执 | 工具、调度、发送结果和编号 | 核对执行和送达 |

DSH 原生上下文管理与压缩负责会话长度，不等于全部聊天自动变成长期记忆，也不等于删除磁盘历史。

本机会话读取连接默认允许的大数据包阈值为 1GiB。这是通信包阈值，不是模型上下文大小，也不是媒体上传上限；模型上下文、附件和不同接口分别计算。

### 9.2 当前主要位置

| 目录 | 用途 |
| --- | --- |
| `data` | 对话数据库、记忆、成员、研究、工具及原版 MCP 数据 |
| `homes` | 各角色 DSH 运行资料和会话 |
| `qq-work\owner-files` | 主人任务未指定位置时的默认产出 |
| `knowledge` | 研究侧资料 |
| `harness` | 角色、权限、连接和运行配置，含本机凭证存储 |
| `vendor` | 运行依赖和已接入的上游项目 |
| `artifacts` | 工程验证结果、截图、验收证据 |

“系统设置 → 数据与升级”显示实际根目录。整理磁盘时按迁移与备份流程核对资料，不能只移动一个启动文件。

### 9.3 清理和保存的实际范围

- 群旁听有短期条数边界，支持按群清理。
- 表情有容量管理与删除入口。
- 长期记忆可纠正、删除、设置过期及禁学信息。
- 当前尚无统一覆盖全部消息、媒体缓存、模型历史的“按天自动清理”总开关。
- 原版 MCP 学习库、Fish 长期记忆和 DSH 历史尚未合并为统一管理视图。

重要资料应检查实际文件、记忆条目并备份；压缩上下文、清理背景和备份是不同操作。

## 10. 常用流程速查

| 目的 | 流程 |
| --- | --- |
| 本地修改文件 | 对话 → 本地工作 → 选目录权限 → 新建 → 交办 → 核对文件 |
| 手机让电脑写文章 | 工作台确认在线 → 主人私聊交办 → 真实工具执行 → 核对路径 |
| 换人格保留聊天 | 人格版本 → 保存或导入 → 选目标 → 不勾新窗口 → 应用重载 |
| 从空白比较人格 | 分别新建窗口，用相同问题试聊 |
| 定时先做事再报告 | 定时任务 → 新建 → 主人目标 → 设时间与正文 → 保存 → 核对文件、回执 |
| 指定 B 站视频 | 视频研究 → BV 号 → 加入任务 → 看详情 → 继续问 |
| 排查不回应 | 连接 → 暂停与额度 → 当前窗口 → 运行错误 → 本轮工具 → 回执 |

## 11. 尚未作为完整工作流交付的内容

- QQ 空间自动动态、配文、评论和账号完整自主生活工作流。
- 任意桌面软件的通用鼠标键盘操控，以及所有格式的完整编辑。
- AstrBot、MaiBot、QQ Agent 全部功能整体移植。
- 所有窗口共用、所有来源统一管理的长期记忆体系。
- 覆盖所有数据类型的统一自动清理与保留策略。
- 关机或后台完全退出后继续执行任务。

当前可直接使用并继续检验的重点：本地编程工作、主人 QQ 远程交办、定时实际执行与发送、人格导入重载、现有资源管理、B 站研究流程。
